FastAPI shell, custom frontend, and the same Python virality engine underneath.

Why this stack fits better now

FastAPI plus custom HTML, CSS, and JavaScript gives ViralScope precise control over layout, spacing, interactions, and visual polish, which is a better fit for a product-grade dashboard.

The backend still uses the same `src/viralscope` modules for cleaning, feature engineering, training, evaluation, and prediction. The frontend simply became more intentional.
